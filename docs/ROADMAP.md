# План развития GeMatch

## v0.1 (в этой ветке)
- [x] Инфраструктура HTML/ES modules без зависимостей
- [x] Разветвлённая карта и циклы забега
- [x] Математические карты и эффекты
- [x] Четыре типа заклинаний, бой и босс
- [x] Алхимия, препятствия, награды, лавка
- [x] Веб-атлас, адаптивная вёрстка
- [x] Локальное сохранение, unit tests, CI
- [ ] Ручной полноценный E2E браузерный прогон

## v0.2
- Багфикс и тесты каждого экрана
- Пошаговый туториал без навязчивых подсказок
- Независимые анимированные слои героя и врагов
- Система draw/discard/exhaust для настоящего колодостроения
- Экономика урона, ограничение повторного использования карт
- Сложность задач по уровням и диагностика ошибок

## v0.3
- 3 региона, 12 врагов, 3 босса
- Открываемые математические операции: дроби, степени, корни
- Рецепты как полноценные уравнения с несколькими ингредиентами
- Алхимическая лавка и события с нелинейными решениями
- Мобильная оптимизация, анимации и звук

## Принципы
- Обычные действия не должны требовать математики.
- Ошибочное решение ослабляет эффект, но не делает ход бесполезным.
- Математика должна быть корректной, включая отрицательные и альтернативные решения.
- Развлекательные механики и обучение тестируются отдельно.
