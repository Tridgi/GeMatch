# GeMatch · Formula Quest

**Математический карточный рогалик про алхимию формул.** Самостоятельный первый вертикальный срез, без платных движков и внешних серверов.

## Как играть
1. Начните новый забег на карте «Лесные руины» и выберите доступный узел.
2. В бою выберите **две числовые карты + одну операцию + одно заклинание**.
3. Нажмите «Применить формулу», решите уравнение для усиления ×1,4. Пропуск даёт ×0,7.
4. В конце хода враг атакует. Обычная атака всегда доступна и стоит 1 энергию.
5. Собирайте новые карты, варите зелья, решайте препятствия и доберитесь до босса.
6. Прогресс забега сохраняется в localStorage, работает без аккаунтов и бэкенда.

## Запуск
Это **статическое веб-приложение** на HTML/CSS/JavaScript ES modules — без установки зависимостей.

```bash
git clone https://github.com/Tridgi/GeMatch.git
cd GeMatch
git switch feature/formula-quest-mvp
python3 -m http.server 5173
```

Откройте http://localhost:5173. В Windows используйте `py -m http.server 5173`. При запуске напрямую через `file://` ES modules могут блокироваться браузером.

## Проверка
```bash
npm test
npm run check
```
CI в `.github/workflows/check.yml` проверяет синтаксис JavaScript, игровые правила и наличие графического атласа.

## Экраны и механики
- **Меню** с показателями метапрогресса и продолжением забега.
- **Маршрут** с развилками, битвами, лабораториями, отдыхом, торговцем, сокровищами и боссом.
- **Сражения**: операции `+`, `×`, `−`; огонь, лёд, щит, лечение; эффект точности уравнений; зелья, вражеские намерения, статусы.
- **Алхимия**: рецепты, ингредиенты, ограничение стабильности, управление пропорциями.
- **Головоломки**: математическое преодоление преград альтернативным рисковым путём.
- **Колода и награды**: карты чисел, операторов и стихий; пополнение после побед.
- **Гримуар** с описанием операций и доступными картами.

### Графика
Художественный атлас `assets/atlas.webp` создан для проекта генерацией изображений в ChatGPT и оптимизирован для веба (12 ячеек: герой, три врага, четыре зелья, кристалл, травы, книга и сундук). Остальной интерфейс нарисован CSS, чтобы держать прототип небольшим и адаптивным. Сгенерированные концепт-экраны используются как ориентир, не выдаются за реальный UI игры.

## Структура
- `src/engine.js` — чистые функции игровых правил и генерации
- `src/main.js` — состояние, маршрутизация экранов и обработчики взаимодействий
- `src/style.css` — оформление и responsive UI
- `assets/atlas.webp` — единый игровой атлас
- `tests/engine.test.mjs` — тесты механики и сохранений

## Статус
**v0.1 — прототип**. Механики работают, но контент и баланс экспериментальные. Не заявляется полноценная JRPG, окончательная графика или release-ready качество. Следующие этапы: UX-проверка в браузере, анимация заклинаний, полноценные события, книга рецептов, обучение, реальный deck/discard/draw, больше врагов и регионов.

Авторский проект GeMatch. Лицензия на распространение кода отдельно не установлена.
